## 프레임 표기 규칙

바이크 LIN 프레임은 **Message ID 1바이트 + 데이터 7바이트**로 다룹니다.

### 바이트 인덱스

| Index | 이름 | 설명 |
|:-----:|:----:|------|
| 0 | Message ID | 프레임 식별자 |
| 1 | Data-0 | 페이로드 |
| 2 | Data-1 | 페이로드 |
| 3 | Data-2 | 페이로드 |
| 4 | Data-3 | 페이로드 |
| 5 | Data-4 | 페이로드 |
| 6 | Data-5 | 페이로드 |
| 7 | Data-6 | 페이로드 |

캡처 뷰어에서 열 `D1`은 Data-0, `D2`는 Data-1입니다. `Dn`은 Data-`(n - 1)`입니다.

일부 필드는 1바이트를 **니블(4bit)** 단위로 나눕니다. 무효 센티넬(바이트 `0xFF`, 니블 `0xF`) 일 경우 데이터가 정확하지 않습니다.

### 비트 순서

비트 **7 = MSB**, 비트 **0 = LSB**.

예: 값 `0xA1`

| 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| 1 | 0 | 1 | 0 | 0 | 0 | 0 | 1 |

- 비트 7–4 → 상위 니블 (MSB nibble) = `0xA`
- 비트 3–0 → 하위 니블 (LSB nibble) = `0x1`

## Message ID 요약

| ID | 상태 | 내용 |
|:--:|:----:|------|
| `0x14` | 분석됨 | 좌측 핸들 버튼, Wonder Wheel In/Out, 회전량, 방향 |
| `0x20` | 분석됨 | 이그니션, 후륜 속도, 주행가능거리, 연료 게이지, 조도 |
| `0x2B` | 분석됨 | 한 프레임에 여러 페이로드. Data-1이 종류를 고릅니다. Data-1이 `0x25`일 때 적산거리 (km). |
| `0x2E` | 미분석 | — |
| `0xE2` | 분석됨 | 엔진 RPM, 기어, 스로틀, 엔진 온도, ASC (Automatic Stability Control), 오일 |
| `0xE9` | 부정확 | 평균 속도, 속도, 전압, 연료 고장, 일반 고장. 이 분석은 정확하지 않습니다. |

## ID `0x14` — 좌측 핸들 / Wonder Wheel

| Data | 상태 | 설명 |
|:----:|:----:|------|
| Data-0 | 미분석 | — |
| Data-1 | 분석됨 | Left Handle Controller 1 (버튼 비트맵) |
| Data-2 | 분석됨 | Left Handle Controller 2 (버튼 비트맵) |
| Data-3 | 분석됨 | Wonder Wheel In / Out |
| Data-4 | 미분석 | — |
| Data-5 | 분석됨 | Wonder Wheel 회전 값 |
| Data-6 | 미분석 | — |

### Data-1 — Left Handle Controller 1

차종: S1000XR 등

| 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| Horn | 방향지시등 취소 | 방향지시등 오른쪽 | 방향지시등 왼쪽 | 크루즈 | 경보 | ABS | ESA |

방향지시등은 한 비트만이 아니라 바이트 전체로도 해석합니다.

| 값 | 신호 |
|:--:|:----:|
| `0x10` | 왼쪽 |
| `0x20` | 오른쪽 |
| `0x40` | 중앙 (취소) |
| 그 외 | 꺼짐 |

비트가 `1`이면 `on`, `0`이면 `off`입니다.

### Data-2 — Left Handle Controller 2

차종: S1000XR 등

| 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| ? | ? | Trip | Info | 크루즈 Set | 크루즈 Reset | 하이빔 | ? |

### Data-3 — Wonder Wheel In / Out

차종: S1000XR 등

| 값 | 의미 |
|:--:|------|
| `0xFD` | Out, 휠 버튼 왼쪽 |
| `0xFE` | In, 휠 버튼 오른쪽 |
| 그 외 | 휠 버튼 꺼짐 |

### Data-5 — Wonder Wheel 회전 값

차종: S1000XR 등

- 범위: `0x00` – `0xFF`
- 이전 프레임과 비교하며, 8비트 오버플로를 감아 넘깁니다. 증가면 `up`, 감소면 `down`입니다.

## ID `0x20` — 이그니션 / 후륜 속도 / 주행가능거리 / 조도

| Data | 상태 | 설명 |
|:----:|:----:|------|
| Data-0 | 미분석 | — |
| Data-1 | 분석됨 | 이그니션, 상위 니블 |
| Data-2 | 분석됨 | 후륜 속도, 하위 8비트 |
| Data-3 | 분석됨 | 하위 니블 = 후륜 속도 상위 4비트, 상위 니블 = 주행가능거리 최하위 자리 |
| Data-4 | 분석됨 | 주행가능거리 나머지 자리. S1000XR 2016에서 게이지 = 주행가능거리 / 250 |
| Data-5 | 분석됨 | 조도, 하위 니블 |
| Data-6 | 미분석 | — |

### Data-1 — 이그니션

상위 니블 `(Data-1 >> 4) & 0x0F`를 사용합니다.

| 값 | 의미 |
|:--:|:----:|
| `0x0`–`0x3` | Off |
| `0x4`–`0x7` | On |
| 그 외 | 공란 |

`0x7F`는 On (`0x7`)입니다.

### Data-2 / Data-3 — 후륜 속도

Data-2가 `0xFF`이면 공란입니다. Data-3의 하위 니블이 `0xF`이면 정확하지 않은 데이터입니다.

```text
rear_wheel_rpm = Data-2 | ((Data-3 & 0x0F) << 8)
```

**타이어 가정 (후륜 190/55ZR17)**

| 항목 | 값 |
|------|-----|
| 유효 지름 | 642 mm |
| 1회전 이동 | 2017 mm |

```text
speed_kmh = (rear_wheel_rpm × 60 × 2017) / 1000 / 1000
```

바이크는 이 타이어 환산(`60 × 2017 / 1_000_000 ≈ 0.121`) 대신 고정 계수 `0.14`를 쓰는 것으로 보입니다.

### Data-3 / Data-4 — 주행가능거리

Data-3의 상위 니블이 `0xF`이거나 Data-4가 `0xFF`이면 정확하지 않은 데이터입니다.

```text
fuel_range = ((Data-3 >> 4) & 0x0F) + ((Data-4 & 0x0F) × 16) + (((Data-4 >> 4) & 0x0F) × 256)
```

S1000XR 2016에서 만탱크 주행가능거리는 약 250 km이므로 연료 게이지는 다음과 같습니다.

```text
fuel_gauge = fuel_range / 250
```

### Data-5 — 조도

하위 니블이 `0xF`이면 정확하지 않은 데이터입니다.

```text
ambient_light = Data-5 & 0x0F
```

## ID `0x2B` — 다중 페이로드 / 적산거리

`0x2B`는 여러 페이로드를 한 프레임에 실습니다. 이 캡처에서 Data-0은 `0x55`이고, Data-1이 종류를 고릅니다. 적산거리는 Data-1이 `0x25`일 때만 해당합니다.

| Data | 적산거리 (`Data-1 = 0x25`) |
|:----:|----------------------------|
| Data-0 | 이 캡처에서 `0x55` |
| Data-1 | `0x25` |
| Data-2 | 하위 바이트 |
| Data-3 | 중간 바이트 |
| Data-4 | 상위 바이트 |
| Data-5 | 거리에 포함하지 않음 |

```text
0x2B  0x55  0x25  Data-2  Data-3  Data-4  Data-5
odometer_km = (Data-4 × 65536) + (Data-3 × 256) + Data-2
```

즉 `(Data-4 << 16) | (Data-3 << 8) | Data-2` 와 동일합니다.

> 바이트 인덱스는 Message ID를 제외한 **Data-n** 기준입니다. 버퍼 배열로 보면 `buf[3]…buf[5]`에 해당합니다.

## ID `0xE2` — RPM / 기어 / 스로틀 / 엔진 온도

| Data | 상태 | 설명 |
|:----:|:----:|------|
| Data-0 | 분석됨 | RPM 하위 바이트 |
| Data-1 | 분석됨 | 상위 니블 = 기어, 하위 니블 = RPM 상위 자리 |
| Data-2 | 분석됨 | 스로틀 위치 |
| Data-3 | 분석됨 | 엔진 온도 |
| Data-4 | 분석됨 | 상위 니블 = ASC, 하위 니블 = 오일 |
| Data-5…6 | 미분석 | — |

### Data-0 / Data-1 — 엔진 RPM

Data-0이 `0xFF`이거나 Data-1의 하위 니블이 `0xF`이면 정확하지 않은 데이터입니다.

```text
rpm = (Data-0 + ((Data-1 & 0x0F) × 255)) × 5
```

### Data-1 — 기어 (상위 니블)

니블이 `0xF`이거나 아래 표에 없으면 공란입니다.

| 값 | 기어 |
|:--:|:----:|
| `0x1` | 1 |
| `0x2` | N |
| `0x4` | 2 |
| `0x7` | 3 |
| `0x8` | 4 |
| `0xB` | 5 |
| `0xD` | 6 |

### Data-2 — 스로틀

Data-2가 `0xFF`이면 공란입니다. `36`이 0%, `236`이 100%입니다. 0% 미만과 100% 초과는 그 범위로 제한합니다.

```text
throttle_percent = ((Data-2 - 36) × 100) / (236 - 36)
```

### Data-3 — 엔진 온도

Data-3이 `0xFF`이면 정확하지 않은 데이터입니다.

```text
engine_temp_c = (Data-3 × 0.75) - 25
```

### Data-4 — ASC (Automatic Stability Control, 상위 니블)

니블이 `0xF`이거나 아래 어느 행과도 맞지 않으면 정확하지 않은 데이터입니다.

| 값 | ASC |
|:--:|:---:|
| `0x1`, `0x9` | 개입 |
| `0x2`, `0x5`, `0x6`, `0x7`, `0xA`, `0xD`, `0xE` | 오류 |
| `0x3`, `0xB` | 자가진단 |
| `0x8` | 비활성 |

### Data-4 — 오일 (하위 니블)

니블이 `0xF`이면 정확하지 않은 데이터입니다.

| 값 | 오일 |
|:--:|:----:|
| `0x2`, `0x6`, `0xA`, `0xE` | 부족 |
| 그 외 | 정상 |

## ID `0xE9` — 평균 속도 / 속도 / 전압 / 고장

아래 `0xE9` 분석은 정확하지 않습니다.

| Data | 상태 | 설명 |
|:----:|:----:|------|
| Data-0 | 부정확 | 평균 속도, 양쪽 니블 |
| Data-1 | 부정확 | 하위 니블 = 평균 속도 상위 자리 |
| Data-2 | 부정확 | 속도 |
| Data-3 | 부정확 | 전압 |
| Data-4 | 부정확 | 상위 니블 = 연료 고장, 하위 니블 = 일반 고장 |
| Data-5…6 | 미분석 | — |

### Data-0 / Data-1 — 평균 속도

Data-0이 `0xFF`이거나 Data-1의 하위 니블이 `0xF`이면 정확하지 않은 데이터입니다.

```text
avg_speed = (((Data-0 >> 4) & 0x0F) × 2) + ((Data-0 & 0x0F) × 0.125) + ((Data-1 & 0x0F) × 32)
```

### Data-2 — 속도

Data-2가 `0xFF`이면 공란입니다.

```text
speed = Data-2 × 2
```

### Data-3 — 전압

Data-3이 `0xFF`이면 정확하지 않은 데이터입니다.

```text
voltage = Data-3 / 10
```

### Data-4 — 연료 고장 (상위 니블)

니블이 `0xF`이면 공란입니다.

| 값 | 연료 고장 |
|:--:|:---------:|
| `0x2`, `0x6`, `0xA`, `0xE` | 고장 |
| 그 외 | 정상 |

### Data-4 — 일반 고장 (하위 니블)

니블이 `0xF`이거나 아래 플래그가 하나도 없으면 아무 문제가 없습니다. 플래그는 동시에 여러 개 켜질 수 있습니다.

| 플래그 | 값 |
|:------:|:--:|
| 황색 점멸 | `0x1`, `0x5`, `0xD` |
| 황색 점등 | `0x2`, `0x6`, `0xA`, `0xE` |
| 적색 점멸 | `0x4`, `0x5`, `0x6`, `0x7`, `0x9` |
| 적색 점등 | `0x8`, `0x9`, `0xA`, `0xB` |
